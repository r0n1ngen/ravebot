A FUN Wi-Fi-controlled ESP-32 robot project intended to develop skills in CAD, laser cutting, coding with Arduino IDE, and breadboard circuit design, 
as well as to build general knowledge of devices such as amplifiers and servo motors.

Current plan is to have the robot/car be controlled via an ESP32 web server that can be opened on any mobile device. Currently considering other methods of robot control.
